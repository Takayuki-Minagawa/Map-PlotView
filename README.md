# Map PlotView

Map PlotViewは、地図上に点・線・面の情報をプロットし、タグや写真、メモと一緒に管理できる静的Webアプリです。
データはYAML / GeoJSON / CSVから読み込め、全体をYAML / GeoJSONで保存、範囲選択した結果をYAML / GeoJSON / CSVで書き出せます。

公開ページ: https://takayuki-minagawa.github.io/Map-PlotView/

## コンセプト

- サーバを用意せず、ブラウザだけで地図プロットを作成・確認する
- タグ、記号、色で地図上の情報を見分けやすくする
- YAMLでデータを持ち運び、必要に応じてGeoJSONやCSVへ変換する
- 現地確認、施設管理、調査地点、候補地、災害・地形情報などを地図上で整理する

## 主な機能

- **地図表示**: 国土地理院タイル、淡色地図、写真、OpenStreetMapを切替
- **オーバーレイ**: 陰影起伏図、色別標高図、活断層図、ハザードマップ（洪水浸水想定・土砂災害警戒区域・津波浸水想定）を重ねて表示。濃さはスライダーで調整
- **場所検索**: 住所・地名（国土地理院の住所検索）や緯度・経度（例: `35.68, 139.76`）で移動し、検索地点をそのまま点として追加
- **現在地表示**: 端末の位置情報で現在地へ移動
- **プロット作成**: 点、線、面を地図上に作図
- **形状編集**: 作成済みプロットの点の移動、線・面の頂点の移動/追加/削除
- **元に戻す / やり直し**: 追加・編集・削除・読込を取り消し（Ctrl+Z / Ctrl+Shift+Z）。線・面の作図中は直前の頂点を取り消し
- **タグ管理**: タグごとに名称、色、記号を設定し、表示/非表示を切替
- **詳細表示**: 座標、表示項目、メモ、写真をサイドビューで確認
- **標高取得**: 点の標高を国土地理院の標高APIから取得し、表示項目に保存
- **写真対応**: 写真のサムネイル表示、ライトボックス表示、EXIF情報の取り込み
- **範囲抽出**: 矩形選択でプロットを抽出し、交差/内包で判定（マウス・タッチ対応）
- **エクスポート**: 全体はYAML / GeoJSON、抽出結果はYAML / GeoJSON / CSVで保存
- **インポート**: YAML、GeoJSON（FeatureCollection）、CSV（点）の読み込みに対応。ファイルのドラッグ&ドロップ可。既存データへの「追加」と「置き換え」を選択可能
- **一覧検索**: プロット一覧を名称/ID/タグで絞り込み
- **全体表示**: 表示中の全プロットが収まるようにズーム
- **多言語表示**: アプリUIは日本語を既定とし、英語へ切替可能
- **簡易マニュアル**: 日本語、中文、英語で表示
- **テーマ切替**: ライトモード、ダークモードに対応
- **レスポンシブ対応**: PC、タブレット、スマートフォンで利用可能

## 使い方

1. 公開ページをブラウザで開きます。
2. `読込`またはファイルのドラッグ&ドロップで保存済みデータ（YAML / GeoJSON / CSV）を読み込みます。初めて使う場合は`サンプル`を選択できます。
3. `場所検索`で目的の場所へ移動するか、`点`、`線`、`面`を選び、地図上にプロットを作成します。
4. 編集画面で名称、タグ、表示項目、メモ、写真を設定します。
5. 一覧または地図上のプロットを選ぶと、詳細ビューで内容を確認できます。`形状編集`で位置や頂点を直せます。
6. `矩形選択`で範囲を指定すると、対象プロットを抽出できます。
7. `保存(YAML)`で全体を保存し、抽出結果はYAML / GeoJSON / CSVで書き出せます。

### キーボード操作

| キー | 動作 |
|------|------|
| `Ctrl+Z`（macOSは`⌘Z`） | 元に戻す（線・面の作図中は直前の頂点を取り消し） |
| `Ctrl+Shift+Z` / `Ctrl+Y` | やり直し |
| `Enter` | 形状編集を確定 |
| `Esc` | 作図・矩形選択・形状編集の取消、ダイアログを閉じる |

作図・矩形選択・形状編集の途中は、元に戻す / やり直しは使えません（地図下部の`キャンセル`または`Esc`で取り消してから操作します）。
スマートフォンなど幅の狭い画面では、これらの操作の間だけ自動で`地図のみ`表示に切り替わります。

## データの扱い

Map PlotViewは静的Webアプリです。読み込んだYAMLや編集内容は、アプリのサーバへ送信されません。
地図タイル、ライブラリ、公開ページの配信には外部サービスを利用します。

- 地図タイル: 国土地理院、ハザードマップポータルサイト、OpenStreetMap
- 場所検索: 検索を実行したときに、入力した住所・地名を国土地理院の住所検索APIへ送信します
- 標高取得: `標高を取得`を押したときに、その点の緯度経度を国土地理院の標高APIへ送信します
- 写真: データ内の写真の参照先（`src`）が`http(s)://`のURLの場合、詳細を開いたときにそのURLから画像を読み込みます。出所の分からないデータファイルを開くときは留意してください
- JavaScript/CSSライブラリ: CDN配信のLeaflet、Leaflet-Geoman、js-yaml、Turf.js、exifr（バージョン固定、SRIで改ざん検知）
- 自動保存: ブラウザの`localStorage`を使用

重要なデータを扱う場合は、保存したYAMLファイルを手元で管理してください。

## YAMLデータ例

```yaml
version: 2
view:
  center: [35.681, 139.767]
  zoom: 13
  baseLayer: pale
  overlays: [afm]
tags:
  - id: site
    name: 建設サイト
    color: "#2e7d32"
    symbol: building
features:
  - id: f001
    type: point
    tag: site
    name: A棟予定地
    coordinates: [35.690, 139.700]
    properties:
      用途: 商業施設
    note: 地権者と交渉中。
    photos:
      - src: a_site_01.jpg
        caption: 北側からの全景
```

座標は緯度経度（WGS84 / EPSG:4326）で保持します。

## CSVの形式

1行目を見出し行として、点を1行1件で読み込みます。文字コードはUTF-8（BOM可）とShift_JIS、区切りはカンマ・タブ・セミコロンに対応します。

| 列（見出し） | 必須 | 内容 |
|------|------|------|
| `lat` / `latitude` / `緯度` | ○ | 緯度（10進数） |
| `lng` / `lon` / `longitude` / `経度` | ○ | 経度（10進数） |
| `id` | | 省略時は自動採番 |
| `name` / `名称` | | 名称 |
| `tag` / `タグ` | | タグID（未定義のタグは自動作成） |
| `note` / `メモ` / `備考` | | メモ |
| `type` | | 本アプリのCSV出力が付ける形状種別。`line` / `polygon` の行は読み飛ばします（それ以外の値は表示項目として取り込み） |
| その他の列 | | 表示項目として取り込み |

```csv
name,lat,lng,tag,用途
A棟予定地,35.690,139.700,site,商業施設
```

抽出結果のCSV出力も同じ列構成（基本列＋表示項目）です。線・面は先頭頂点を代表点として出力するため、CSVから形状を復元することはできません。
CSVは表計算ソフトとの受け渡し用の簡易形式です（メモの改行は空白になり、写真や記号の上書きは含まれません）。データを完全な形で保存・受け渡しするにはYAMLを使ってください。

## GitHub Pages公開

`main`ブランチへpushされると、GitHub Actions（Linuxランナー）が構文チェックとユニットテストを実行し、成功後にGitHub Pagesへ公開します。
手動で再公開したい場合は、GitHub Actionsの`Deploy GitHub Pages`ワークフローを`workflow_dispatch`で実行できます。

GitHub Actionsは公開時にのみ使用します。プルリクエストでは自動実行されないため、マージ前に手元で確認してください。

```bash
npm ci
npm run check
npm test
```

## ライセンスと出典

地図タイルを利用する際は、画面上に表示される各提供元の出典表示に従ってください。
OpenStreetMap、国土地理院タイル、ハザードマップポータルサイトのオープンデータ、国土地理院の住所検索・標高API、その他外部ライブラリの利用条件は、それぞれの提供元の規約・ライセンスに従います。
住所検索・標高APIはサーバに過度な負荷を掛けない範囲で利用してください（本アプリは利用者の操作時にのみ問い合わせます）。
